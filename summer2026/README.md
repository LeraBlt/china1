# 🇨🇳 China Dreams — Интерактивный веб-проект о Цзинани

Проект представляет собой современный адаптивный веб-сайт, посвященный культурно-языковому лагерю в Китае. Основной акцент сделан на визуальном повествовании и плавном пользовательском интерфейсе.

## 🚀 Ссылка на проект
[Посмотреть сайт вживую](https://chinadreams.ru)

## 🛠 Технологии
* **Frontend:** HTML5, CSS3 (Flexbox & Grid).
* **JavaScript:** Кастомная логика для интерактивной карусели, медиа-сетки, меню и расписания.
* **Оптимизация:** Использование форматов WebP/AVIF для высокой скорости загрузки (Lighthouse Score ~90+).
* **Инструменты дизайна:** Figma (прототипирование), Squoosh (оптимизация изображений).

## ✨ Ключевые особенности
* **Custom Media Carousel:** Самописная карусель с поддержкой фото и видео, адаптированная под мобильные устройства (touch-swipe).
* **Производительность:** Реализована ленивая загрузка (`lazy loading`) и явные размеры изображений для предотвращения Layout Shift (прыжков контента).
* **Адаптивный дизайн:** Сайт корректно отображается на всех устройствах — от смартфонов до широкоформатных мониторов.
* **SEO & Домен:** Настроен кастомный домен с поддержкой HTTPS и корректными DNS-записями (CAA/CNAME).
